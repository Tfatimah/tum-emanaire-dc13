# From Answers to Possibilities — TUM EMANAIRE DC13

A standalone, independent research microsite by Tasneem Fatima. Not an official TUM/EMANAIRE website.

## Files
- index.html: interactive dark research microsite
- proposal.html: accessible reading-copy of the research proposal
- research-proposal.pdf: upload the approved, two-page PDF to this path for the embedded PDF viewer
- netlify.toml: static Netlify deployment settings

## Deploy
On Netlify, select **Add new project → Import an existing project → GitHub**, select `Tfatimah/tum-emanaire-dc13`, choose `main`, leave build command blank, and set publish directory to `.`.

**Before making the site public**, upload the approved `research-proposal.pdf` to the repository root. The PDF is publicly accessible once hosted.
